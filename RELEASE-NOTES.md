# Folio 1.0.0 release candidate

The final v1 pass improves daily recording, explains the financial model and applies one visual system across the app. Domain calculations, security and persistence files are unchanged in this pass.

- Complete transaction history with incremental loading and session filter retention.
- Faster amount entry, Save and add another, and a session-only last-used account.
- Guarded entry dialogs, keyboard focus management, field-linked errors and explicit destructive confirmations.
- Phone-specific transaction, schedule and debt rows, readable mobile reports and reachable form actions.
- Account totals, recorded surplus, scheduled money and manually maintained debt have explicit scopes.
- Goals show contribution counts, estimated completion and combined active-plan demand; linked balances can overlap.
- Health checks show supplied-input results and unknown states, without an overall score. Targets use a friendly percentage input without changing stored ratios.
- Dashboard surfaces recorded facts and direct actions. Reports default category analysis to a month with records and rank spending categories.
- Settings concentrates preferences and data safety; About & Support contains Folio, ANVA, privacy, AI disclosure and passive optional support.
- Navy/dark and warm/light themes use consistent typography, icons, spacing, restrained surfaces and stronger text contrast.

No data migration, new accounting semantics, persisted shared assumptions, allocations, Health Score, savings-allocation advice, scheduled-payment matching or bank sync is introduced.
